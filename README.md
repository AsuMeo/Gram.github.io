# Tsuyu

Tsuyu — тёмный веб-клиент приватного мессенджера: личные и групповые чаты, голосовые и видеозвонки, реакции, файлы, избранное, быстрый поиск и экран проверки ключа. Интерфейс работает без фреймворков и внешних зависимостей, поэтому его можно открыть на GitHub Pages или отдать с любого статического сервера.

> В текущем репозитории находится готовый UI-прототип клиентской части. Сетевой transport и криптографический backend намеренно не имитируются в браузере. Для настоящего production E2EE используйте описанную спецификацию и проверенные криптографические библиотеки — нельзя проектировать собственные математические примитивы шифрования.

## Запуск локально

Нужен Python 3 или Node.js.

```bash
# Python
python3 -m http.server 8080

# либо Node.js
npx serve . -l 8080
```

Откройте `http://localhost:8080`. Для GitHub Pages достаточно включить Pages из ветки `main` (корень `/`).

## Запуск на своём сервере

Пошаговая инструкция с Nginx, HTTPS, заголовками безопасности, systemd и reverse proxy находится в [docs/DEPLOY.md](docs/DEPLOY.md).

```bash
git clone https://github.com/KamiSakyy/Gram.github.io.git tsuyu
cd tsuyu
# скопируйте содержимое в web root или настройте Nginx на эту папку
```

Клиент использует только относительные URL, поэтому backend можно подключить за тем же доменом без обращений к `localhost` из браузера.

## Production-план

- [Архитектура и C++-сервисы](docs/ARCHITECTURE.md)
- [Tsuyu Secure Messaging Protocol v0.1](docs/PROTOCOL.md)
- [Деплой клиента и API](docs/DEPLOY.md)

Рекомендуемый production-стек: C++20, Boost.Asio или standalone Asio для WebSocket, PostgreSQL для метаданных, S3-совместимое object storage для зашифрованных вложений, Redis/NATS для fan-out и libsodium/BoringSSL для криптографии. Ключи сообщений создаются на устройствах пользователей; сервер хранит только ciphertext и минимальные маршрутизационные метаданные.

## Возможности демо

- переключение личных и групповых чатов;
- фильтры «Все», «Непрочитанные», «Избранное» и поиск;
- отправка сообщений клавишей `Enter`, многострочный ввод через `Shift + Enter`;
- эмодзи, mock-вложение, voice recording state, реакции, reply/actions;
- аудио- и видеозвонок с экраном состояния;
- профиль чата с общими медиа и fingerprint ключа;
- окно нового диалога и настройки приватности;
- responsive layout для планшета и телефона;
- локальный интерфейс без градиентов и без внешних CDN-ресурсов.

## Важное о безопасности

Название «Tsuyu» — это дизайн и спецификация протокола, а не заявление о пройденном аудите. До публичного запуска нужны независимый криптографический аудит, тестирование threat model, fuzzing, проверка push-уведомлений, безопасное хранение ключей в Keychain/Keystore и воспроизводимые сборки. Подробные ограничения и этапы перечислены в `docs/PROTOCOL.md`.
